# Payroll Calculator

A beginner C++ console application created for CSC-120. The program collects an employee's hours worked and hourly pay rate, generates a four-digit employee ID, calculates gross and average pay, and displays the results in an aligned payroll table.

## Features

- Accepts hours worked and hourly pay rate from the user
- Generates a random employee ID from 1000 to 9999
- Calculates gross pay and average hourly pay
- Formats monetary values to two decimal places
- Displays results in an aligned console table

## Concepts Practiced

- Variables and named constants
- Console input and output
- Arithmetic calculations
- Random-number generation
- Type conversion
- Output formatting with `iomanip`

## Build and Run

```bash
g++ -std=c++17 payroll_calculator.cpp -o payroll_calculator
./payroll_calculator
```

On Windows, run `payroll_calculator.exe` after compiling.
